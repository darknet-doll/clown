# Bubble Housing — v0

The floral piece on the back of the hand that hides the kit's blower head
([DESIGN.md](../../DESIGN.md)). Not designed yet. This file currently holds the
reference geometry it will be built from.

## Ground Truth

### Reference: "Bubble Gun Toy" REV1 (third-party pocket for the same kit)

- **Source:** MakerWorld, designer Matthew Ghost, "Bubble Gun Toy", Model Revision #1
  (2024-12-14, added air holes to 01/02_Body)
- **License:** MakerWorld Standard Digital File License — **no redistribution**. The
  repo is public, so the model files stay out of git (see `.gitignore`)
- **Local files** (gitignored, present on darknetdoll's machine only):
  - `reference/bubble-gun-toy/Bubble_Gun_REV1.3mf` — original download
  - `reference/bubble-gun-toy/stl/*.stl` — all 11 parts, regenerated by `extract.py`
  - `reference/bubble-gun-toy/body-01-depth-map.png` — 01_Body seen from the split face
- **Committed:** `extract.py` (3MF → STLs) and `bore.py` (bore radius table)
- **What it is:** a gun that houses the **same Bambu Electric Bubble Maker Kit 01** we
  have. So its blower pocket was sized to the real blower head. It is **a pocket that
  fits the head, not a drawing of the head**

**Frame** (designer's assembly frame, as extracted):
- z = barrel axis. **z = −5 is the muzzle face**, +z runs back toward the grip
- Barrel axis at x = 0, y = 0. Body halves split on the x = 0 plane
  (01 = x < 0, 02 = x > 0)
- **+y is down** (trigger guard and grip are on +y), −y is the top

**Overall body** (01 + 02 joined): 44.8 (x) × 71.5 (y) × 177 (z) mm

**Layout, front to back:**

| z (mm) | What | Measured from |
|---|---|---|
| −5 → 46.6 | **Blower head pocket**, round, open at the muzzle | ray-cast bore table |

| 56 → 113 | Bottle bay, 32 wide × ~20.5 tall, hatch on the bottom (03_Cover) | depth map |

### From the designer's assembly notes (text, not measured)

- Hose from the blower head to the bottle lid: **50–70 mm**. Hose inside the
  bottle, lid to gravity ball: **50 mm**
- Silicone sleeve (from the kit) goes on the lid; the lid must stay one-way
- Kit cables run in a groove in 01_Body
- Fasteners: 6 × BT2×8 self-tapping screws

## Constraints

- Blower head intake must stay open. The REV1 revision added the top air holes
  specifically for "better airflow", so a closed shell starves the blower
