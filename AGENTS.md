# Working in this repo

## Commit and push when done

When you finish a piece of work, commit it and push it. Don't wait to be asked.

- Commit straight to `main`. Don't create branches.
- Stage only the files your work touched. Leave unrelated changes in the working tree alone.
- Split unrelated changes into separate commits. Each subject line should say what changed and why, not "update files".
- If the push is rejected, run `git pull --rebase` and push again. If the rebase hits a conflict, stop and report it. Never force-push.
